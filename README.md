# Sistema de Desconto

Programa desenvolvido em Python para calcular descontos progressivos de acordo com o valor total da compra.

## Regras de desconto

- Compras abaixo de R$ 200,00: 5% de desconto.
- Compras de R$ 200,00 até abaixo de R$ 300,00: 10% de desconto.
- Compras a partir de R$ 300,00: 15% de desconto.

## Funcionamento

O programa solicita ao usuário o valor total da compra, calcula o desconto correspondente e exibe o valor do desconto e o valor final a pagar.

## Linguagem utilizada

- Python
